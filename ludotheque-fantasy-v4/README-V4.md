# La Ludothèque V4 — habillage fantasy

Cette version reprend le code de la V3 et ajoute les illustrations fournies par l’utilisateur sous `public/art/`. Les plateaux interactifs restent de vrais éléments HTML ; les images servent d’illustrations et de textures, car leurs chiffres ne sont pas suffisamment fiables pour être utilisés comme grille de jeu.

## Import GitHub
Importer le contenu de ce dossier à la racine du dépôt, en remplaçant les fichiers existants `src/main.jsx` et `src/style.css`. Conserver `.github/workflows/android-apk.yml`. Le commit sur main déclenche la construction de l’APK.

## Attention
Les règles des dames et du jeu de l’oie restent simplifiées, comme dans la V3. Les images ne sont pas les cases cliquables.
